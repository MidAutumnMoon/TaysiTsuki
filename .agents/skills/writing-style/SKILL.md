# 文风提示词编译

## 〇、核心认知

1. **示例比指令强十倍。** LLM从示例学到的东西，比从指令学到的多得多。两者冲突时，LLM跟示例走。
2. **提示词的语气会传染给输出。** 提示词用口语，输出偏口语；提示词用书面语，输出偏书面。用目标文风的语气来写提示词本身。
3. **好文章大部分句子是普通的。** 重点段靠大量普通句子撑起来；句句都是重点，也就没有重点了。
4. **LLM不知道什么时候该克制，除非你明确告诉它。** 它默认同时用上所有学到的手法。
5. **每种文风有它的推进方式。** 靠信息增量、意象叠加、情绪变化、还是事件动作往前走。LLM默认把任何文风往氛围、抒情方向读——读错推进方式，写出来的只在形式上像，内容是空的。


## 一、执行入口

当被调用时，输入是 1-N 段目标文风的样本文字，输出是一个完整的 writing prompt，由三块按顺序组成：

```
叙述者设定（叙述者是谁、文字靠什么走、情绪怎么进文字）
    ↓
限制（约束和禁令）
    ↓
示例（完整节奏的示范，附批注）
```

**叙述者设定放在限制前面。** LLM先读到"你是什么样的叙述者"，再读到限制，写作时的心态完全不同。反过来，LLM会进入"执行规范"的心态，输出工整但冷。

执行流程：

```
1. 提取：从样本读出可观测特征（含推进方式）
2. 叙述者设定：把特征翻译成叙述者关系
3. 限制：先上基线，再按偏向补特异限制
4. 示例：套用样本，补普通段和批注
5. 自评自改：生成试写 -> 检查偏向 -> 调限制 -> 重试
```


## 二、提取

从样本里读出可观测特征，把每个翻译成叙述者设定或限制的具体要素。

| 维度 | 观测什么 | 翻译到哪 |
|---|---|---|
| 句长节奏 | 短句为主还是长句为主？有没有短-短-长的爆发模式？ | 叙述者设定（叙述者是急是缓）+ 限制（节奏配额） |
| 词汇层级 | 书面/口语/方言比例？有没有行业术语或生造词？ | 叙述者设定（叙述者身份）+ 限制（词汇禁区） |
| 叙事距离 | 全知？限知第三人称？贴近主角？纯客观旁观？ | 叙述者设定（叙述者是谁） |
| 对话/叙述比 | 靠台词推还是靠叙述推？ | 叙述者设定（场景靠什么走）+ 示例选段 |
| 修辞模式 | 偏好哪种修辞（重复、对仗、比喻）？密度多高？ | 限制（技法配额）+ 示例选取 |
| 文气重心 | 情绪压在开头？结尾？全程压着？最后爆发？ | 叙述者设定（情绪怎么进文字）+ 示例选段 |
| **推进方式** | 场景靠什么走：信息增量（事实、来历、细节知识）？意象叠加？情绪变化？事件动作？细节是知识性的还是装饰性的？ | 叙述者设定（叙述者有无东西要讲 + 内容载体）+ 限制（按推进方式定禁令）+ 示例选段 |

提取不是量化打分，是读出"这个叙述者和读者之间是什么关系"。七个维度是观测角度，不是填表。

**推进方式是七维里最容易被漏读的。** LLM默认把文风理解成氛围，会把信息驱动的样本也读成"安静有审美的旁观者"。提取到这一行时，先问：这些细节删掉哪个，场景就站不住？删掉一个事实或一段来历，场景就站不住——这是信息推进；删掉一个意象才站不住——这是意象推进。判断错了，后面全错。


## 三、写叙述者设定

### 3.1 找到叙述者设定

问：**"这种文风里，叙述者和读者之间是什么关系？"**

> 下表为示例，非穷举。

| 文风 | 叙述者在干嘛 |
|---|---|
| 口语叙事 | 一个有脾气的人在给你讲事 |
| 悲伤 | 一直想避开某件事，但每个念头最后都落到它身上 |
| 科幻 | 面对超出日常尺度的东西，用人能理解的尺度去解释 |
| 悬疑 | 知道的比说出来的多，每句话都在选择性透露 |
| 荒诞 | 所有人一本正经做蠢事，叙述者假装没发现 |
| 热血 | 情绪全程外放，随时要爆发 |

### 3.2 写成提示词

用一段人话写清楚四件事：
- **叙述者是谁**（纯客观记录者？八卦邻居？冷眼旁观者？）
- **场景靠什么走**（角色在要什么？在怕什么？在藏什么？）
- **场景靠什么推进**（信息增量？意象？情绪？动作？没有内容载体时这个文风会变成什么？）
- **情绪怎么进入文字**（直接渗进选词？克制地只露一点？全程压着最后爆发？）

用目标文风的语气来写这段话。别用术语。

**推进方式这一条尤其要写进叙述者设定。** 如果文风是信息驱动的，要说清楚叙述者"有东西要讲"——温雅来自讲得从容，不来自无话可说；要声明这文风需要一个被讲述的对象，没有内容载体时拒绝纯氛围写作。漏了这一条，限制再严也止不住内容空洞。

### 3.3 常见错误

- ❌ 把态度/语气/温度当作"技法"跟因果链、造词并列 -> LLM会限量使用态度
- ✅ 态度是全篇都在的默认状态；技法只是点缀，限量使用
- ❌ 在叙述者设定里写完整段落而非抽象特征 -> LLM会照抄段落，叙述者设定该是关系描述不是范文
- ❌ 把信息驱动的文风读成氛围驱动，叙述者设定写成"安静有审美的旁观者" -> 输出必空洞；推进方式没写进叙述者设定


## 四、写限制

### 4.1 限制的层次

限制分两层，先上基线再补特异：

- **基线限制（所有文风默认上）**：没东西可写了就换场景，别硬凑；台词已经说过的，旁白不再重复；结尾不升华、不抒情、不总结。
- **特异限制（按文风偏向后补）**：不提前猜。先拿叙述者设定+示例生成一版，看它往哪偏，再针对性加限制。

> 下表为示例，非穷举。

| 文风 | LLM最容易偏向哪 |
|---|---|
| 口语叙事 | 修辞密度失控、每句都在炫技 |
| 悲伤 | 煽情、反复咀嚼同一种痛、滥用比喻 |
| 科幻 | 设定倾泻、术语堆砌、角色变成讲设定的工具 |
| 悬疑 | 故弄玄虚、暗示太多、节奏拖沓 |
| 荒诞 | 每句抖机灵、笑点密度失控 |
| 热血 | 形容词堆砌、每段都是重点 |

### 4.2 限制的写法原则

**给数字，不给形容词。**
- ❌ "适当控制密度"、"偶尔使用"
- ✅ "连续五句最多一句上技法"、"角色出场时外貌最多写一处"

**分硬禁和软限两层。**
- 硬禁：一违反就看得出来（如：结尾不升华、不用某种句式）
- 软限：大致遵守就行（如：五句最多一句技法、感官一种写完就走）

**直接调配额数字做微调。**
- 输出太平、太冷 -> "五句最多一句"改成"四句最多一句"
- 输出技法密度过高 -> 反过来调

**按推进方式定禁令。** 提取出推进方式后，针对性加限制：
- 信息推进 -> 禁纯景物氛围堆砌；每个细节必须带信息或推进认知；写"海面亮"就得说清它为什么亮、在什么时段、跟哪件事有关
- 意象推进 -> 禁信息倾泻、禁术语堆砌，意象可以叠加但不许塞知识
- 情绪推进 -> 禁事件铺陈盖过情绪主线，情绪的流转才是主轴


## 五、写示例

### 5.1 核心原则

**展示完整节奏，不要只展示重点段。**

- ❌ 只给重点段切片 -> LLM以为正常写作就该是这个密度
- ✅ 普通段 -> 重点段 -> 普通段，让LLM看到技法前后应该长什么样

**示例3-5段，覆盖不同场景强度。** 节奏随文风变——下表示范同一套思路怎么套到不同文风：

| 口语叙事 | 悲伤文风 |
|---|---|
| 日常对话（长，完整） | 日常中突然想起来 |
| 安静暧昧（短，因果链示范） | 长段回忆 |
| 一笔带过（极短，物件带人味） | 一笔带过的痛 |
| 旁观者视角（中，情绪嵌入） | 跟别人说话时装没事 |
| 情绪爆发（密，一口气不断） | 独处时崩溃 |

**"普通段"不等于"电报体"。**
- ❌ "A推开门进去了。桌上三个杯子。她坐下。" -> 电报体，零温度，也零信息
- ✅ "A翻了半天柜子找打火机，翻到第三个抽屉放弃了，顺手拿火柴凑合。" -> 零技法，但有动作和信息撑着，语气自然带出来

普通段不是"没东西写"，是"写得平常"。平常的句子也可以推进信息、交代事情，它只是不上技法。普通段可以靠信息或动作支撑，不必靠意象。信息驱动的文风，普通段一旦写成纯氛围，就是在制造空洞。

### 5.2 批注的写法

**只讲人物在要什么、怕什么、藏什么。不讲技法。**

- ❌ "因果链两环：水溅->躲->撞上，停。"
- ✅ "两个人都想挨着，身体自己做了决定，嘴上谁都没提。"

LLM会模仿批注的关注焦点。批注盯技法，它写的时候想"该用什么技法"；批注盯人物动机，它写的时候想"这个人现在想要什么"。

### 5.3 示例里的句式会被泛化

如果示例里出现一种有辨识度的句式（如"不是X，是Y"），LLM会在输出里反复使用。在示例中出现的任何句式，默认会被当作"推荐句式"。要么控制它在示例中的出现频率，要么在限制里显式说明。


## 六、自评自改

每轮只解决一个问题。同时改太多东西分不清是哪个改动起了作用。

```
生成一版试写
    ↓
对照限制检查：它往哪偏了？
    ↓
偏向 -> 针对性加特异限制 / 调配额数字
    ↓
重新生成，看新问题
    ↓
重复直到不再偏
```

调参方向有三个，别只盯密度高低：

- **输出太平、太冷**（工整但没人味）-> 检查叙述者设定是否到位（态度是否被当技法限量了），放宽技法配额
- **输出技法密度过高**（每句炫技、失控）-> 收紧技法配额，加普通段包裹，检查示例是否全是重点段
- **输出空洞**（有氛围无增量、景物堆砌但不推进、形式像那个文风但内容是空的）-> 这是第三种失败，不是密度问题。检查提取是否漏了推进方式维度；检查叙述者设定是否声明了内容载体；检查限制里有没有按推进方式加上"禁景物堆砌"。这种文风空写必空洞，得给它一个被讲述的对象


## 七、陷阱速查

遇到症状，按此索引定位：

| 症状 | 查哪节 |
|---|---|
| 输出每句都在炫技，密度失控 | 5.1（示例全是重点段）+ 4.2（收配额） |
| 指令说克制，示例全是满载 | 〇.1（示例>指令，改示例） |
| 输出工整但冷，没有人味 | 3.3（态度被当技法） |
| "适当"、"偶尔"被忽略 | 4.2（换数字） |
| 输出碎、短、电报体 | 5.1（普通段写成电报体） |
| 同一种句式出现四五遍 | 5.3（句式泛化） |
| 散文化，每个感官翻来覆去写 | 加特异限制：感官一笔过不反刍 |
| 教冷峻文风但提示词嘻嘻哈哈 | 〇.2（用目标文风语气写提示词） |
| 输出规矩但没有生命力 | 一（叙述者设定放限制前） |
| 空洞、景物堆砌没增量 | 二（提取漏推进方式）+ 3.2（叙述者设定声明内容载体）+ 4.2（按推进方式定禁令） |
