# LLM 文风提示词工程 — 完整方法论

## 〇、核心认知

1. **范例比指令强十倍。** LLM从范例学到的东西远超指令。两者冲突时，LLM跟范例走。
2. **提示词的语气会传染给输出。** 提示词用口语，输出偏口语；提示词用书面语，输出偏书面。用目标文风的语气来写提示词本身。
3. **好文章大部分句子是普通的。** 名场面靠普通句子养出来，一桌子全是肉没法吃。
4. **LLM不知道什么时候该克制，除非你明确告诉它。** 它的默认行为是把所有学到的东西同时开满。


## 一、搭建提示词的结构

提示词只需要三块，按顺序排列：

```
发动机（文字的驱动力和温度）
    ↓
刹车（限制和禁令）
    ↓
范例（完整节奏周期的示范，附批注）
```

**发动机放在刹车前面。** LLM先读到"你是什么样的叙述者"，再读到限制，写作心态完全不同。反过来的话，LLM进入"执行规范"的心态，输出工整但冷。


## 二、写发动机

### 2.1 找到发动机

问自己：**"这种文风里，叙述者和读者之间是什么关系？"**

| 文风 | 叙述者在干嘛 |
|---|---|
| 热血口语 | 一个有脾气的人在给你讲事儿 |
| 悲伤 | 绕开一个不敢直视的东西，但每条路都绕回去 |
| 科幻 | 站在太大的东西面前，试图用人能理解的尺度去丈量 |
| 悬疑 | 知道的比说出来的多，每句话都在选择性泄露 |
| 荒诞 | 所有人一本正经做蠢事，叙述者假装没注意到 |

### 2.2 写成提示词

用一段人话写清楚三件事：
- **叙述者是谁**（摄像头？八卦邻居？冷眼旁观者？）
- **场景靠什么往前走**（角色在要什么？在怕什么？在藏什么？）
- **情绪怎么进入文字**（直接渗进选词？克制地只露一点？全程压着最后爆发？）

用目标文风的语气来写这段话。别用术语。

### 2.3 常见错误

- ❌ 把态度/语气/温度当作"技法"跟因果链、造词并列 → LLM会限量使用态度
- ✅ 态度是底色，全篇都要有；技法是调料，限量使用


## 三、写刹车

### 3.1 找到刹车

**不要提前猜。** 先拿发动机+范例让LLM写一版，看它往哪滑，再针对性加限制。

每种文风的失控方向不同：

| 文风 | LLM最容易往哪滑 |
|---|---|
| 口语叙事 | 修辞密度失控、每句都在炫技 |
| 悲伤 | 煽情、反复咀嚼同一种痛、滥用比喻 |
| 科幻 | 设定倾泻、术语堆砌、角色变成设定的嘴替 |
| 悬疑 | 故弄玄虚、暗示太多、节奏拖沓 |
| 荒诞 | 每句抖机灵、笑点密度失控 |
| 热血 | 形容词爆炸、每段都是高潮 |

### 3.2 刹车的写法原则

**给数字，不给形容词。**
- ❌ "适当控制密度"、"偶尔使用"
- ✅ "连续五句最多一句上技法"、"一个人出场外貌最多一处"

**分硬禁和软限两层。**
- 硬禁：违反了一定会注意到的（如：结尾不升华、不用某种句式）
- 软限：大致遵守即可的（如：五句最多一句技法、感官一种写完就走）

**用最直接的旋钮做微调。**
- 输出太淡 → "五句最多一句"改成"四句最多一句"
- 输出太浓 → 反过来调

### 3.3 万能刹车（对所有文风有效）

- 没东西可写了就换场景，别注水
- 台词传达过的，旁白不重复
- 结尾不升华、不抒情、不总结


## 四、写范例

### 4.1 核心原则

**展示完整节奏周期，不要只展示高光。**

- ❌ 只给名场面切片 → LLM以为正常写作就该是这个浓度
- ✅ 白开水 → 名场面 → 白开水，让LLM看到技法前后应该长什么样

**范例3-5段，覆盖不同场景强度。**

以口语叙事为例：
1. 日常对话（长，完整）
2. 安静暧昧（短，因果链示范）
3. 一笔带过（极短，物件带人味）
4. 旁观者视角（中，情绪嵌入）
5. 情绪爆发（密，一口气不断）

换成悲伤文风可能是：
1. 日常中突然想起来
2. 长段回忆
3. 一笔带过的痛
4. 跟别人说话时装没事
5. 独处时崩溃

**"白开水"不等于"冷水"。**
- ❌ "A推开门进去了。桌上三个杯子。她坐下。" → 电报体，零温度
- ✅ "A翻了半天柜子找打火机，翻到第三个抽屉放弃了，顺手拿火柴凑合。" → 零技法，但有语气

### 4.2 批注的写法

**只讲人物在要什么、怕什么、藏什么。不讲技法。**

- ❌ "因果链两环：水溅→躲→撞上，停。"
- ✅ "两个人都想挨着，身体自己做了决定，嘴上谁都没提。"

LLM会模仿批注的关注焦点。批注盯技法，它写的时候想"该用什么技法"；批注盯人物动机，它写的时候想"这个人现在想要什么"。

### 4.3 范例里的句式会被泛化

如果范例里出现一种有辨识度的句式（如"不是X，是Y"），LLM会在输出里反复使用。在范例中出现的任何句式，默认会被当作"推荐句式"。要么控制它在范例中的出现频率，要么在刹车里显式限制。


## 五、迭代流程

```
1. 找三段你喜欢的目标文风文字（别人的或自己写的）
2. 问自己：叙述者在干嘛？→ 写成发动机
3. 把文字当范例，补上白开水包裹层和批注
4. 让LLM写一版，看它往哪滑
5. 针对滑向加刹车
6. 再跑一版，看新问题
7. 重复 4-6 直到满意
```

**每轮只解决一个问题。** 同时改太多东西分不清是哪个改动起了作用。


## 六、常见陷阱速查

| 陷阱 | 症状 | 解法 |
|---|---|---|
| 范例全是高光 | 输出每句都在炫技，密度失控 | 范例加白开水包裹层 |
| 指令和范例打架 | 指令说克制，范例全是满载 | 改范例，别加更多指令 |
| "调味"被当技法限量使用 | 输出工整但冷，没有人味 | 把态度从技法板块移到发动机 |
| 限制用形容词不用数字 | "适当"、"偶尔"被忽略 | 换成具体数字和频率 |
| 白开水写成冷水 | 输出碎、短、电报体 | 白开水范例加语气（"也懒得拧"） |
| 范例中某个句式被泛化 | 同一种句式出现四五遍 | 刹车里显式限制，或改范例 |
| 叙述者停下来品味感受 | 散文化，每个感官翻来覆去写 | 加"感官一笔过不反刍"，禁"不是X是Y" |
| 提示词语气和目标文风不匹配 | 教冷峻科幻但提示词嘻嘻哈哈 | 用目标文风的语气重写提示词本身 |
| 刹车太多没有发动机 | 输出规矩但没有生命力 | 发动机放在刹车前面，先定温度再定规矩 |
